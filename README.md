# Garuda Dome System (GDS)

Repository prototype untuk platform multi-domain nasional Indonesia yang mengintegrasikan:
- Air defense / pertahanan udara
- Disaster management
- Cyber / hoaks / disinformation
- Karhutla
- Illegal logging
- Illegal fishing
- Narcotics
- Social stability
- Extreme weather and environmental monitoring

## Struktur Repo

- `index.html` — dashboard v3 prototype interaktif multi-tab
- `docs/proposal-gds-final.md` — proposal final versi lengkap
- `docs/gds-demo-script.md` — naskah demo video 3–4 menit
- `docs/gds-slide-outline.md` — outline 15 slide
- `docs/thumbnail-direction.md` — arahan visual thumbnail / screenshot dashboard

## Cara Menjalankan

Karena ini dibuat sebagai prototype static HTML, Anda cukup membuka file langsung di browser, atau jalankan server lokal:

```bash
cd /path/to/garuda-dome-system
python3 -m http.server 8000
```

Lalu buka:

```text
http://localhost:8000
```

## Fokus Konsep

GDS dirancang dengan prinsip:
- decision support + early warning + koordinasi
- human-in-the-loop
- open architecture
- dual-use capability
- multi-intelligence fusion
- cross-domain correlation
- scalable mulai dari data publik hingga intel aktif
